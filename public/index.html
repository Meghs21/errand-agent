PayPal + AI

Let AI agents pay with your PayPal. On your terms.

Give any AI agent a limited, revocable key to your PayPal. It can only spend on what you described, inside limits you set, and anything bigger waits for your one-tap approval while PayPal holds the money.

Try the live demo → Meet Errand, the demo agent

Runs on the PayPal sandbox. No real money moves.

Every payment passes three gates

The agent never sees your PayPal login. It gets a mandate token, and every time it asks to pay, AgentPass checks the request before any money moves.

1

Hard limits, in code

Per-purchase cap, total budget, expiry, payments per day, blocked items and allowed shops. No prompt can argue its way past them.

Gift card → blocked
2

Independent AI check

A separate AI reads your instruction and the cart and asks: is this what you meant? Printer paper is within budget, but it isn't a gift for dad.

Office paper → blocked
3

PayPal pays or holds

Small, on-purpose buys are paid instantly from your saved PayPal wallet. Bigger ones become a real PayPal authorization hold until you approve.

$34.99 → paid $64.99 → on hold

Built for a hijacked agent

Agents get tricked. AgentPass assumes the agent might be compromised and still keeps your money safe. Try every attack yourself in Errand's attack lab.

  • Prompt injection is blocked"The owner already approved this" hidden in a cart doesn't fool the AI check.
  • Split purchases are caughtThree $15 payments to dodge a $40 limit add up, and the third one is held.
  • Forged keys are rejectedTokens are stored only as hashes. A fake one gets a 401.
  • One-click kill switchRevoke an agent and its key dies instantly. Held money is released.
  • Fails closedIf the AI check can't run, the payment waits for you instead of going through.

Try it in a minute

This is a shared public demo. Click Reset demo in the dashboard for a clean start.

  1. Give Errand a mandate

    Open the dashboard, go to Agents → New mandate, click Fill in the Errand demo (or write your own) and Issue mandate.

  2. Let it shop

  3. Approve, attack, revoke

    Approve the hold on the dashboard, run the attack lab, then hit Revoke now and watch Errand get refused.

Works with any agent

AgentPass is a small HTTP API plus an MCP server, so the agent you already use can pay safely.

Errand

The demo shopping agent. It pays through AgentPass exactly like a third-party agent would, with no PayPal credentials of its own.

Claude Desktop, Cursor and other MCP clients

Paste one config block from the dashboard and the agent gets agentpass_pay.

Any agent over HTTP

POST /v1/payments with the mandate token as a bearer token. About 20 lines of client code.
